# Semantic review

- Controlled-one готовит только локальные Google/Yandex preview.
- Имя клиента допускается лишь при точном разрешённом сопоставлении; иначе
  фиксируется как неподтверждённое.
- Полный диалог не попадает в общую базу знаний и внешне не публикуется.
- Реальная смысловая приёмка невозможна до отдельного разрешения на один звонок;
  поэтому `semantic_pass=false`, `business_pass=false`.
