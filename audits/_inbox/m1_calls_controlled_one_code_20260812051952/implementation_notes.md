# Что сделано

- Добавлен неизменяемый owner-only запрос ровно на один звонок с привязкой к
  SHA, host и изолированному runtime.
- Controlled-one выполняет точное двойное перечисление закрытого окна,
  проверяет официальный total, allowlist и не меняет production cursor.
- Полный локальный путь сделан последовательным: Whisper, очистка памяти,
  GigaAM, Resolve, Analyze, Timeline staging и локальные preview.
- Добавлены единый lock, lifeline дочерних процессов, восстановление после
  падения и доказанный пустой повтор без дублей.
- Readback Timeline проверяет tenant, тип события и логический эффект SQLite.

# Как проверялось

- 681 профильный и смежный тест на Python 3.12.13.
- Отрицательные проверки: неполный список Mango, чужой звонок, изменённый
  запрос, потеря Timeline, SIGKILL родителя, mutation production cursor,
  повтор готового состояния.
- Аудиты Claude Opus/Fable/Sonnet и независимые роли Codex.
- Финальный breaker PASS после отрицательных проверок загрязнения и удаления
  Timeline staging; architect PASS для следующего разрешённого шага.
