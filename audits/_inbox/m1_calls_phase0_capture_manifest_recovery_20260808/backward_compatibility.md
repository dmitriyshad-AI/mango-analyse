# Обратная совместимость

- Основной `capture_manifest.jsonl` сохраняет прежнюю схему записей.
- Новый ledger имеет отдельную схему и читается только capture recovery-кодом.
- Старый запуск без ledger получает эквивалентное пустое resolved-состояние.
- Обычный `partial` по недоступному аудио по-прежнему может опубликовать
  проверенные звонки в Process B, сохраняя красный итог дня.
- Только tail-recovery усиливает gate: cursor и новый ready drop блокируются до
  долговечного красного отчёта и чистого повтора.
- Идентичность inode действует только в живом экземпляре Store. Новый процесс
  после завершённого офлайн-переноса принимает новый inode; межрестартовая
  сверка остаётся обязанностью Phase 0 inventory/relocation.
- Реальные callers Whisper и GigaAM уже выполняются последовательно; этот блок
  не меняет порядок, модели или параметры распознавания.
- ASR, Resolve, Analyze, модели и форматы готового отчёта менеджера не менялись.
