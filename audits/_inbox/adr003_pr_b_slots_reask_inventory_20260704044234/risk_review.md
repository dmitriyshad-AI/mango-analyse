# Риски

## Клиентский риск

Низкий: PR-B не отправляет новый текст и не автономизирует ответ. При включении он влияет только на список `do_not_ask_again`.

## Главные риски

- Если hidden values попадут в prompt, бот может начать утверждать неподтверждённый класс/предмет/формат. Закрыто sentinel-тестами и микро-замером.
- Если `SLOTS_REASK` начнёт сам создавать hidden slots, появится скрытая память без `slots_gsf`. Закрыто no-op тестом.
- Если sim/update точки не пробросят reading, измерения PR-B будут ложно зелёными. Закрыто static guard на 3 вызова.
- Если live будет запущен без memory-provenance/profile persistence, hidden slots не сохранятся после ответа и `SLOTS_REASK` не даст эффекта. Это функциональный no-op риск, не клиентский риск; перед включением нужен profile/runtime smoke.

## Live/write

Live bot, Wappi, AMO, Tallanto, CRM не трогались. Внешних записей нет.
