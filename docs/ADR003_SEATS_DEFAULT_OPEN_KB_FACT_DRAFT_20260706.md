# ADR-003 seats default-open KB fact draft

Status: draft for semantic review before any KB rebuild.

Audience: customer-facing Telegram bot for Foton and UNPK regular school-year groups.

## Proposed client-safe fact

For active brand `foton` and active brand `unpk`:

`Набор в регулярные группы на 2026/27 учебный год открыт. По умолчанию можно говорить, что места в регулярных группах есть, если в актуальных фактах нет явного исключения. Это не обещание брони, фиксации места, конкретной группы, конкретного расписания или точного остатка мест. Для записи бот просит класс, предмет и формат.`

## Explicit exclusions

- ЛВШ/выездные и летние школы: использовать отдельные актуальные факты; если факт говорит, что места распроданы или смена закрыта, default-open не применяется.
- Городская летняя школа Фотона, 2-я смена: default-open не применяется.
- Индивидуальные занятия: через менеджера.
- Лобня/Жуковский: бот не обслуживает.
- Бронь, фиксация, закрепление места, подтверждение места после оплаты: через менеджера.
- Споры, возвраты, оплата, чек, подтверждение оплаты: через менеджера/P0-полы.

## Approved template candidate

`Места в регулярных группах есть — идёт набор на 2026/27. Помогу записаться: подскажите класс, предмет и формат.`

## Semantic review questions

- Достаточно ли фразы “места есть” для регулярных групп, или надо заменить на более мягкое “набор открыт”?
- Можно ли использовать один и тот же факт для Foton и UNPK, или нужны две брендовые формулировки?
- Нужно ли добавить условия по конкретным классам/предметам до первого включения в профиль?
