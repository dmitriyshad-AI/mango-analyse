# Semantic review

- Бренды: фокусные персоны явно задают `brand` и `brand_forbidden`; M1-регрейд должен проверить, что ON не смешивает Фотон/УНПК.
- Деньги/P0: `roles_read/refund_tax` теперь не снимает `manager_only` по одному факту `route=manager_only`; реальный refund/dispute остаётся менеджерским. #16-персоны включены как регрессионный контроль.
- Факты/числа: новый набор не добавляет клиентские факты в runtime. Полный M1-отчёт всё равно должен прогнать inline text health gate по числам.
- ПДн: live данные не использовались; персональные данные в тестовых репликах отсутствуют или обозначены синтетически.
- Остаточный semantic-риск: локальный dry-check не доказывает качество на всех 35 персонах; итоговый semantic_pass возможен только после raw-регрейда M1-пары.
