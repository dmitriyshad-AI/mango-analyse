# Semantic Review

## Проверено

Ключевая смысловая граница сформулирована явно:

- "существует ли курс/лагерь/формат для класса X" без просьбы записать или
  проверить места — стабильная справка;
- "есть места", "можно попасть", "забронируйте", "запишите" — живое действие
  менеджера.

Новый prompt запрещает frame считать `draft_for_manager` или текст
"менеджер проверит" доказательством того, что сам клиентский запрос требует
менеджера.

10, `too_confident` остался 0. Это улучшает читателя смысла, но не даёт права
самостоятельно отвечать клиенту: `strict_active_candidates_now=0`.
