# Риски

- Клиентский риск: внешней публикации нет; локальный preview не выдаёт
  неподтверждённое ФИО за факт.
- Данные/записи: production cursor и production Timeline запрещены; точный
  controlled request и до/после snapshot проверяются fail-closed.
- Откат: старый runtime не менялся; новая работа находится в отдельной ветке и
  изолированном `$HOME/.mango_local`-контракте.
- Остаток: точное состояние старого Mac и последние обработанные call_id на M1
  пока не перенесены и не подтверждены.
